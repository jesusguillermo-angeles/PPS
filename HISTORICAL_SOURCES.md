## Reconstruction policy
- Verified historical names, categories and mechanics are implemented as data/rules.
- Surviving screenshots supplied by the user are used directly as visual references/assets.
- When an event-specific original image is not present in the supplied archive, the project uses a clearly reconstructive visual rather than claiming it is an original asset.
- Hidden server RNG values are not presented as exact historical values unless documented.
